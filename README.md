# export-guidance-system

project name : export-guidance-system
This project was made for beginner entrepreneur. Beginner intrepreneur who wants trade with another countries was served information about best export terms. 
Because of this project, intrepreneur exporting to foreign countries will increase and it is possible to expect foreign currency earnings from other countries.

Features :
  It can expect 'Golden Time' for exporting specific item if you enter that item and etc.
  It can calculate estimated customs duty.
  It can serve many information for trading(exchange rate, demand curve, estimated sales)

Tech Stacks :
  python
  database(sql)
  streamlit
